# HexBrowns による追加

σ軸さんの [Path_S](https://github.com/sigma-axis/aviutl2_script_Path_S)（v2.30）をフォークしたものです。

| ファイル              | 内容                                                                            | 説明書                       |
| ----------------- | ----------------------------------------------------------------------------- | ------------------------- |
| `@連結ライン_Hex.anm2` | 複数のオブジェクトの位置を線でつなぐ。線の先細りと太さの波、2 つの位置を腕のように曲げてつなぐ 2関節IK も使える。線の描き方は ラインσ@Path_S に準拠し、`Path_S.lua` を使うため `Path_S` の導入が必要 | [docs](docs/連結ライン_Hex.md) |

## 導入
使用したいスクリプトを `Script` から取り出し、AviUtl2の `Script` フォルダへコピーして、AviUtl2 を起動します。
元のスクリプトとは名称が違うため競合の心配は不要です。
